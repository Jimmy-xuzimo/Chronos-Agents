## 验证边界

- WebKit 自动化不等于 iOS Safari 实机；本轮未在 iPhone、Android、平板、macOS 或 Firefox 实机验证。
- 84 组是 CSS 视口与明暗组合，不代表 200% 文字缩放或所有操作系统字体组合均已验证。
- 本轮网页动效检查不代表 Windows / macOS 应用动效、硬件采集或安装生命周期重新验收。
- GitHub Actions 部署成功与公开页面回读需在推送后另外确认，不能用本地通过代替上线结果。

设计文件维护与发布方式见 [Chronos Pages 维护说明](CHRONOS_WEBSITES.md)；项目关系见 [三项目接入指南](CHRONOS_ECOSYSTEM.md)。
