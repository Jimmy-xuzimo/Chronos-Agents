# Windows 客户端 1.0.1

- 与 Widgets 1.2.0 共用嵌入式彩色桌面设计参数，统一主次文字、强调色、按钮和圆角；保持无主题轮询、无装饰动画。
- 修复采集核心默认配置目录：使用 Windows 当前用户 RoamingAppData 已知文件夹，与原生窗口一致，避免启动环境变化读取到空绑定。
- 安装入口、快捷方式和自启动显式保留配置目录；原生窗口保存设置不再丢失启动目录。
- 保留现有 DPAPI 登录与设备凭据。本次是 Windows 安装包修订；Hub、macOS 和 Android 不在本次二进制发行范围。

构建：C# 原生窗口、Go Windows 核心、Inno 安装器。截图使用虚构数据；公开版本不含服务器、账号、配对码或设备 Token。升级前后需核对持续上传；未以重启整机代替用户当前工作会话。
