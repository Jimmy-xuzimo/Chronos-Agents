# Chronos Agents 1.0.0

首个正式版本：多端统一采集，数据发送到自己部署的 HTTPS Hub。

## 平台与界面

- **Windows：**沿用电脑采集器的性能摘要与双栏原生界面，托盘常驻、登录自启动。管理密码可由 DPAPI 记住，不再依赖本机管理网页。
- **macOS：**SwiftUI 原生窗口、菜单栏后台核心与钥匙串；支持当前用户 LaunchAgent 登录自启动，提供 Intel 和 Apple Silicon 构建。
- **Linux / NAS：**保留带认证的网页管理端口；原生服务或非 root Docker，不挂载 Docker socket。
- **Android：**原生 Compose App；前台实时采集、WorkManager 后台周期上报。发行 APK 使用已有独立私钥签名。
- **Hub：**独立接收服务、一次性配对、逐设备凭据、范围受限只读连接、历史、审计、保留时限与可选 TOTP。

## 本版修正

修复重新配对和清理参数；工作台适配层保留响应结构、设备顺序与切换前历史。统一协议、指标单位和能力状态，不用零伪造缺失数据。默认关闭进程、主机名和网卡地址，需两端同时允许。

## 下载与部署

- Windows：`Chronos-Agent-1.0.0-windows-x64-setup.exe`。
- Windows / Linux Agent + Hub：对应平台的 `chronos-agents-1.0.0-*` 压缩包。
- macOS：对应架构的 `chronos-agent-macos-*-unsigned.tar.gz`。
- Android：`chronos-agent-1.0.0-android.apk`。
- Docker / NAS：对应架构的 agent 和 hub 镜像归档，先解压再导入。

新部署先配置 Hub 的 HTTPS，再初始化管理密码并创建配对码；不能使用旧工作台 Token 代替配对码。桌面应用内部保留仅绑定 loopback 的本机 API，原生窗口不使用 WebView / Electron。

## 验证范围

Go 测试、Linux race detector、Windows 安装 / 运行中升级 / 配置保留 / 卸载、macOS 双架构原生编译与 Keychain helper、Android Debug / Release 构建和 Lint、Docker 双架构构建均由 CI 检查。发布工作流另行校验来源、扫描发行归档并生成 SHA256 和构建来源清单。

前序 fnOS 真机联调验证宿主指标、只读根、独立卷、HTTPS、暂停恢复、撤销和 Hub 重启持久化；前序 Android 16 模拟器四项测试通过。最终 Windows 界面截图使用虚构数据。

尚未完成 macOS 原生窗口实机交互、Android 厂商省电 / 长期后台、NAS 系统重启和长期压力测试；CI 与模拟器不替代这些结果。Windows 无商业代码签名，macOS 未签名 / 公证；请从官方 Release 下载并核对 SHA256。

本版不包含远程命令、多用户 RBAC、自动更新、逐磁盘长期图表或纯容器 cgroup 指标。Apache-2.0；第三方许可和 BOM 随包提供。
