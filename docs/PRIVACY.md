# 隐私说明

采集器只向用户配置的单个 Hub 主动上报。无第三方分析 SDK、广告、崩溃上报或自动发现公网服务；管理页不加载 CDN 字体或远程图像。二维码由 Hub 本地生成。

基础数据包括 CPU、内存、卷容量、网卡计数、系统版本和 uptime。可选的主机名、网卡地址与进程名称可能揭示设备或软件使用信息，默认关闭，且需要本地和中心同时授权。磁盘名称／卷标签和网络接口名称同样可能包含用户自定义文字，公开截图前需要人工检查。

不读取或上传通讯录、短信、位置、剪贴板、浏览器历史、硬件序列号、文件正文、进程命令行参数或环境变量。电池策略仅读取供电状态和系统电量。

本地持久配置包含服务器地址、设备 ID、采样控制、CA 公共证书、管理密码哈希以及平台保护的设备凭据。业务样本只在 RAM，正常退出或重启即清空；本版无离线磁盘队列。操作系统崩溃转储、交换文件与宿主管理员仍可能接触进程内存，不宣称抵御这些权限。

Hub 默认保留原始基础样本 24 小时、分钟汇总 30 天、审计 90 天，可在管理页修改。最新快照可保留进程名称，历史排除进程模块。关闭敏感项后客户端丢弃旧队列；Hub 对新上报再次过滤。关闭不会自动清除先前备份；彻底清除需在受控维护窗口清理相关数据与备份。

撤销设备阻止继续上报，并不等于删除历史。断开客户端会清除本机设备凭据，不会删除 Hub 数据。彻底卸载前建议在 Hub 撤销，再删除本机配置；Android 清除应用数据会移除本机配置与 Keystore 引用。

日志只记录启动、错误分类和数量，不记录 Authorization、Cookie、配对码、私钥或指标正文。公开仓库的示例均使用虚构地址；发行前对源码和二进制分别检查，手工复核仍有必要。
